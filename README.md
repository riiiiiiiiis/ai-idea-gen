# Vibecoding: Генератор Идей

Простое веб‑приложение на React + Vite, которое с помощью Gemini генерирует 5 свежих идей для веб‑приложений на русском языке. Подходит как источник вдохновения для быстрых pet‑проектов и экспериментов с AI‑разработкой.

## Возможности
- Генерирует 5 идей за один запрос
- Подсказки по профессиям для быстрого старта (предустановленные темы)
- Копирование готовых промптов одним кликом с подтверждением
- Обработка ошибок и понятные сообщения на русском

## Стек
- React 19, TypeScript
- Vite 6
- Google Gemini (`@google/genai`)

## Запуск локально

**Требования:** Node.js 18+

1) Создайте файл `.env.local` в корне проекта и укажите ключ Gemini:
   
   ```bash
   GEMINI_API_KEY=ваш_api_ключ
   ```
   
2) Установите зависимости:
   
   ```bash
   npm install
   ```
   
3) Запустите dev‑сервер:
   
   ```bash
   npm run dev
   ```

Приложение будет доступно на адресе, указанном Vite (обычно `http://localhost:5173`).

## Сборка и предпросмотр

```bash
npm run build
npm run preview
```

## Конфигурация окружения
- Приложение ожидает переменную `GEMINI_API_KEY` (см. `vite.config.ts`).
- В рантайме она прокидывается как `process.env.API_KEY` для `services/geminiService.ts`.

Ключевые файлы:
- `services/geminiService.ts` — обращение к Gemini и схема ответа
- `vite.config.ts` — прокидывание env‑переменных в клиент

## Примечания
- Не публикуйте ваш `GEMINI_API_KEY` в репозиториях. Используйте `.env.local`, который не должен коммититься.
- Если видите ошибку «API_KEY environment variable not set», проверьте, что `GEMINI_API_KEY` задан и dev‑сервер перезапущен.
